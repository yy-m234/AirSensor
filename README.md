# ✈️ AirSensor : IoT 기반 객실 쾌적도 모니터링 시스템

ESP8266과 온습도/조도 센서를 활용하여 실내 환경을 실시간으로 분석하고, 
쾌적도 점수를 산출하여 맞춤형 숙소를 추천하는 웹 플랫폼입니다.

## 🔗 프로젝트 링크
* **웹사이트 확인하기:** [https://yy-m234.github.io/AirSensor/]

## 📁 파일 구성
* `index.html` : AirSensor 웹 플랫폼 화면 (디자인, 필터링, Chart.js 시각화)
* `airsensor1007.ino` : ESP8266 데이터 수집 및 AP모드 웹 서버 코드


## ⚙️ 실시간 데이터 테스트 방법 (AP 모드)
본 프로젝트의 하드웨어는 자체 공유기 역할(AP 모드)을 수행합니다. 실시간 센서 값을 웹에서 확인하려면 아래 절차를 따라주세요.
1. 스마트폰이나 노트북의 Wi-Fi 설정에서 `yeyoung_room` 네트워크에 연결합니다. (비밀번호: `12345678`)
2. 위 프로젝트 웹사이트 링크에 접속합니다.
3. 3초마다 '내 방 실시간 상태' 카드의 센서 수치와 차트가 갱신되는 것을 확인합니다.
